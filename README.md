## How it works

`main.ts` is a dependency-free Node program. It holds the line above as a constant and checks that it is 1–200 characters, a single line and not only whitespace. It then writes the line to `entry.txt` in the directory named by `MAKEFUN_OUTPUT_DIR` (default `/output`), creating the directory if needed. The file contains the line exactly, with no trailing newline.

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

Node 22.18 or newer runs a `.ts` file directly. The file uses only erasable type annotations, so Node strips them without a build step.

## Why this line

The field of 1,487 entries is full of gross-out toppings (wet socks, toothpaste, sardines) and legal-personification gags ("the crust filed for divorce"). This line wins on the judge's own order: it names a pizza and a topping that is genuinely awful (inedible paper), lands one clean turn (the topping is still billing you, for an insultingly exact $47.32), and stays a single deadpan pitch in one breath. In glm-5.3-flash duels it beat the Matryoshka frequent-flyer mini-pizza 2–0 (margins 2+3) and the $75 parking-ticket pie 2–0 (margins 2+2); the judge's reason in both was the same — one joke, fully landed, with a precise joyless number, versus two stacked gags.
